# One Page Website Project

This is a simple one-page website built using HTML, CSS, and JavaScript. The project was created to practice front-end web development skills and understand how to build a structured, responsive webpage.

---

## 📌 Project Overview

This website includes different sections on a single page such as:

- Home
- About
- Projects
- Contact

It uses smooth navigation so users can scroll through all sections easily.

---

## 🧰 Technologies Used

- HTML
- CSS3 
- JavaScript 
---

## 🖼️ Features

- One-page scrolling layout  
- Navigation bar with section links  
- Image gallery section  
- Responsive design basics
